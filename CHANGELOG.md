## [0.1.0] - 2026-10-12

### Added

- Monotonic timing with aggregated metrics and individual traces.
- A no-op profiler implementation for disabling measurements.
- `ServerTimingFormatter` for HTTP `Server-Timing` response headers.
- Standalone PHPUnit tests and GitHub Actions.
